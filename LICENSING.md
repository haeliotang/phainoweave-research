# Research snapshot licensing template

The public research snapshot remains permissive:

| Material | Licence |
|---|---|
| Research code | Apache-2.0 |
| Documentation and release prose | CC-BY-4.0 |
| Project-owned synthetic evidence bytes published under CC0-1.0 | CC0-1.0 |
| Project name, wordmark and logo | `LicenseRef-Inceptless-Brand` |

Contributions require the Inceptless CLA in `CLA.md`. Sign it at
<https://cla-assistant.io/haeliotang/phainoweave-research>. A PR is merged only
after the CLA check (`license/cla`) passes.

The next export must use a new manifest revision outside `release/phase1/`.
