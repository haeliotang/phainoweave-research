| Material | Proposed licence |
|---|---|
| Research source code (`python/`, `scripts/`, `containers/`, E0 config) | Apache-2.0 (root `LICENSE`) |

## Official licence texts

- Apache-2.0: <https://www.apache.org/licenses/LICENSE-2.0>
- CC BY 4.0: <https://creativecommons.org/licenses/by/4.0/legalcode>
- CC0 1.0: <https://creativecommons.org/publicdomain/zero/1.0/legalcode>

The repository `LICENSE` is the Apache-2.0 text for software code. The CC BY 4.0 and CC0 1.0 proposals are separate licences for documentation and synthetic evidence; they are not replaced by the root software licence.

## Code-in-documentation rule

If a document contains a code block copied from source, the code block is governed by Apache-2.0; the surrounding prose, tables and figures are CC BY 4.0. If a document links to source rather than reproducing it, the link target remains Apache-2.0.

## Rights confirmation

See `RIGHTS-CONFIRMATION.md`. The confirmation covers the candidate materials, not a public-release authorization.

## Evidence ownership

The C2-C archive is synthetic output generated by this project's code and declared protocols. It contains no real recordings, personal data or third-party datasets. The maintainer confirmed on 2026-11-07 that the generation inputs and synthetic evidence are sufficiently controlled to make the CC0-1.0 dedication; third-party materials remain excluded.

## Third-party material

No third-party datasets, raw audio, images or vendored source are included in the candidate snapshot. Runtime dependencies are not redistributed; their licences are listed in `THIRD_PARTY.md`.

## Ethical statements are not licence terms

The README's non-military, non-surveillance and non-personal-tracking statements are research-ethics scope statements. They do not add legally enforceable restrictions to Apache-2.0 or CC BY 4.0 rights.
