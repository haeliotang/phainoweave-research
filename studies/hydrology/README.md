# PW-H — Hydrology series

**Status:** proposed; no public preregistration or result
**Framework:** [Empirical Limits of Physical-World Observability](../../docs/research/observability-program.md)

## Proposition family

For a fixed river reach and a declared time window, can the evidence establish whether the target cross-section stage is above or below a preregistered threshold?

## Measurement mechanisms under study

- weather radar reflectivity and a declared rainfall retrieval;
- fixed-view imagery only when it is lawfully usable and does not expose a gauge readout;
- upstream hydrological observations as dependent evidence, not as independent truth.

## Independent reference

A quality-controlled target stage record must be retained outside all inference inputs. Products that assimilate that gauge, including some multi-source precipitation products, are not independent evidence.

## Current status

Proposed. No site, event window, public preregistration or result is frozen. This page does not claim a hydrology capability or a camera capability.

## Public outputs expected at each gate

- G0: lawful data and independent-reference audit;
- G1: explicit hydrological forward model and nuisance bounds;
- G2: feasible stage sets and counterexamples;
- G3/G4: real-data and locked-validation packages, if the evidence supports them.

A null or `undetermined` result is acceptable. No result exists yet.
