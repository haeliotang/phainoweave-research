# Security policy and research boundary

This is a research snapshot, not a deployed service.

- Do not use this code to locate, track, or profile people, private residences, or operational activities.
- Do not connect it to live data sources or real recordings without a separate authorization and ethics review.
- Report a suspected vulnerability privately to the maintainer rather than opening a public issue with exploit details.
- The snapshot has no production identity, authorization, signing, or OS-sandbox enforcing layer. Its README and limitations describe the boundaries; they are not a substitute for an operational security review.
